🎯 COMECE POR AQUI - SUAS DÚVIDAS RESPONDIDAS:

1. ERRO AO RODAR DOCKER-COMPOSE?

   Problema: "unable to get image" ou "cannot find dockerDesktopLinuxEngine"

   Solução:
   ✅ Abra Docker Desktop (menu Iniciar Windows)
   ✅ Aguarde ficar verde
   ✅ Teste: docker ps
   ✅ Execute: docker-compose up --build -d

   Warning "version obsolete" = IGNORE (só um aviso)

---

2. PRECISO CRIAR ARQUIVOS .env?

   ✅ SIM, para rodar localmente

   Em cada serviço, criar .env baseado no .env.example:

   cd auth-service
   cp .env.example .env

   cd ../doctors-service
   cp .env.example .env

   cd ../patients-service
   cp .env.example .env

   Para AWS: Use AWS Secrets Manager (não precisa .env)

---

3. ONDE CRIAR REPOSITÓRIO GITHUB?

   ✅ Criar NOVO repositório separado: "medical-microservices"

   Passos:
   1. Criar novo repo no GitHub (não inicializar com README)
   2. Copiar pasta microservices para novo local
   3. git init + git push

   O diretório .github/workflows JÁ ESTÁ CRIADO dentro de microservices/

   Detalhes completos: GITHUB_SETUP.md

---

4. API GATEWAY (NÃO LOAD BALANCER)

   ✅ Tudo adaptado para AWS API Gateway HTTP API

   Arquitetura:
   Cliente → API Gateway → VPC Link → NLB (interno) → ECS Services

   NLB ainda é necessário mas fica PRIVADO (só API Gateway acessa)

   Detalhes completos: AWS_APIGATEWAY_SETUP.md

---

5. REGIÃO AWS

   ✅ Tudo configurado para us-east-2

   Arquivos atualizados:
   - GitHub Actions workflow
   - 3 Task Definitions
   - Toda documentação

   Todos os comandos AWS já usam --region us-east-2

🚀 COMANDOS MAIS USADOS:

Local:
  docker-compose up --build -d      # Iniciar tudo
  docker-compose logs -f            # Ver logs
  docker-compose down               # Parar
  curl http://localhost:3001/health # Testar

AWS:
  aws ecr create-repository --repository-name medical-auth-service --region us-east-2
  aws ecs create-cluster --cluster-name medical-microservices-cluster --region us-east-2

GitHub:
  git init
  git add .
  git commit -m "Initial commit"
  git push origin main
